# Conversation Context Sync Protocol

## Purpose
Preserve all creative, biometric, architectural, and operational directions across sessions without relying on volatile chat memory.

## Sync Targets
1. `memory-bank/activeContext.md`: Immediate priorities, active component focus, active bugs/features.
2. `memory-bank/progress.md`: Completed deliverables, upcoming milestones, verification passes.
3. `memory-bank/systemPatterns.md`: Algorithms, Table 1.1 weightings, UI tokens, component architecture.
4. `memory-bank/techContext.md`: Ports, dependencies, database state, API endpoints.
5. `memory-bank/productContext.md`: User personas, client goals, ethical DMIT standards.
